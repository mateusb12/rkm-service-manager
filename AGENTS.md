# Regras do repositório

- Nunca crie, troque ou publique uma branch nova por conta própria.
- Trabalhe sempre na branch atual do usuário, normalmente `main`.
- Para pedidos de commit e push, faça o commit e o push diretamente na branch atual.
- Só use outra branch se o usuário pedir explicitamente.
- Não inclua arquivos locais, bancos, segredos ou artefatos gerados sem confirmação.
