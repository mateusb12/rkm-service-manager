# Regras de code review

## Nomes devem ser descritivos

Use nomes que expressem claramente a responsabilidade e o contexto do código.

## Exemplos

- Evitar: `ChipMulti`
- Preferir: `MultiSelectCheckboxes`
- Evitar: `DataCard`
- Preferir: `ServiceOrderSummaryCard`

## Sem abreviações

Não use abreviações em nomes de variáveis, mesmo para variáveis auxiliares.

### Exemplos

- Evitar: `opt`, `err`, `obj`, `exc`
- Preferir: `option`, `error`, `object`, `exception`
